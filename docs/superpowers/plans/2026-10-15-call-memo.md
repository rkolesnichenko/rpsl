# A call's own filter memo — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stop a `-c 4` sweep's lints from recomputing the filter answers that other workers evict from the shared memo (AS31117, AS1101 time out today), and let a `Checker` without `Memo` keep an IXP lint's answers.

**Architecture:** `resolve.NewFilterMemoOver(shared, maxRanges)` returns a `FilterMemo` layered over a shared one: it answers from itself, then from `shared`, and stores what is computed in both. `consist.Checker.eval` gives every evaluator (one per call) such a layer over `Memo.filters`, bounded like the shared memo; without `Memo`, its own memo's bound rises from 1<<18 to 1<<21.

**Tech Stack:** Go 1.23 floor, `resolve` and `resolve/consist` (resolve module), memguard-guarded real-data runs on RIPE's dumps.

**Spec:** `docs/superpowers/specs/2026-10-15-call-memo-design.md` (approved 2026-10-15). Read it first; this plan argues from it.

## Global Constraints

- `go.mod` floors stay at go 1.23; no new dependency.
- No result changes: every answer through a layer is the answer recomputation gives (same `filterKey`, same `memoizable` rule, same quarter rule).
- Engine purity: `cd resolve && go list -deps . ./consist` must not include `net`.
- API surface: `api/resolve.txt` gains exactly `func NewFilterMemoOver(*FilterMemo, int) *FilterMemo`; regenerate with `RPSL_API_UPDATE=1 go run ./internal/apisurface -check` from the repo root and review the diff; `go run ./internal/apisurface -check` must pass.
- Heavy runs (real data, check.sh with fuzz) one at a time, under `.superpowers/sdd/tools/memguard.sh`, `GOMAXPROCS=4`, never beside each other.
- Every figure written into docs or the CHANGELOG comes from a command run on this branch in this work; anything not measured is called unknown.
- Commit only on branch `call-memo`; push and PR only after the user says so.

## Review Focus

1. A layer whose bound is smaller than its shared memo's: an answer from `shared` heavier than a quarter of the layer's bound is returned (a hit) but not kept in the layer — never an error, never a wrong answer. → Task 1, `TestFilterMemoOverSmallerLayer`.
2. An `Expander` with `Exclude` set and a layer as `Memo`: the memo (layer and shared) is ignored entirely, as for a plain `FilterMemo`. → Task 1, `TestFilterMemoOverIgnoredWithExclude`.
3. A call cancelled mid-lint: its context error is stored in neither the layer nor the shared memo, so the next call (rpslcheck's next aut-num after a `-check-timeout`) recomputes. → Task 1, `TestFilterMemoOverStoresOnlyWhatSharedWould`.
4. Many calls at once over one shared memo too small for them, the sweep's shape: every Lint and Check equals the unmemoized one. → Task 2, `TestMemoConcurrentEvicting` (under `-race` in check.sh).
5. `NewFilterMemoOver(nil, n)`: behaves as `NewFilterMemo(n)`, no nil dereference. → Task 1, `TestFilterMemoOverNilShared`.

```go
// NewFilterMemoOver returns a FilterMemo bounded as NewFilterMemo(maxRanges)
// is, layered over shared: a lookup it cannot answer itself is answered from
// shared when shared holds the key, and the answer is then kept in the layer
// too; an answer computed through it is stored in the layer and in shared,
// each by its own rules. A hit in the layer does not touch shared. Use one
// for one call's evaluations, so that what shared evicts while the call runs
// is not computed again; shared must serve the same snapshot (see
// FilterMemo). A nil shared makes it NewFilterMemo(maxRanges).
func NewFilterMemoOver(shared *FilterMemo, maxRanges int) *FilterMemo {
	m := NewFilterMemo(maxRanges)
	m.shared = shared
	return m
}
```

```go
// get returns the stored answer for k, if any — the layer's own, or else
// shared's, which the layer then keeps — and counts the lookup. It never
// holds the layer's lock and shared's together.
func (m *FilterMemo) get(k filterKey) (*filterAnswer, bool) {
	m.mu.Lock()
	if el, ok := m.entries[k]; ok {
		m.stats.Hits++
		m.pool(k).lru.MoveToFront(el)
		a := el.Value.(*filterAnswer)
		m.mu.Unlock()
		return a, true
	}
	m.mu.Unlock()
	if m.shared != nil {
		if a, ok := m.shared.get(k); ok {
			m.mu.Lock()
			m.stats.Hits++
			m.keep(a)
			m.mu.Unlock()
			return a, true
		}
	}
	m.mu.Lock()
	m.stats.Misses++
	m.mu.Unlock()
	return nil, false
}
```

```go
// store adds a, unless its error does not follow from the inputs alone, to
// m (see keep) and then to shared.
func (m *FilterMemo) store(a *filterAnswer) {
	if a.err != nil && !memoizable(a.err) {
		return
	}
	m.mu.Lock()
	m.keep(a)
	m.mu.Unlock()
	if m.shared != nil {
		m.shared.store(a)
	}
}

// keep adds a to m's own pool, unless m holds its key already or it weighs
// over a quarter of the bound, evicting the least recently used answers of
// the pool to keep it within the bound. m.mu is held.
func (m *FilterMemo) keep(a *filterAnswer) {
	if _, ok := m.entries[a.key]; ok {
		return // another goroutine computed it too
	}
	if a.weight > m.max/4 {
		return
	}
	p := m.pool(a.key)
	m.entries[a.key] = p.lru.PushFront(a)
	p.held += a.weight
	for p.held > m.max {
		back := p.lru.Back()
		old := back.Value.(*filterAnswer)
		p.lru.Remove(back)
		delete(m.entries, old.key)
		p.held -= old.weight
	}
}
```

```go
// eval is c.Eval with Expander.Exclude cleared, Src memoizing its aut-nums
// and inet-rtrs, and a filter memo of the call's own. With c.Memo, Src reads
// through it, and the filter memo is a layer over c.Memo's (see
// resolve.NewFilterMemoOver), bounded as c.Memo's is: the call keeps what it
// computes or fetches until it returns, so other calls evicting it from the
// shared memo cannot make it compute an answer twice (beside three other
// lints, RIPE's AS31117 took 2m21s that way; 7.7 s alone). Without c.Memo,
// a per-call policyMemo, and, unless Eval.Expander.Memo is set, a per-call
// filter memo bounded as a default Memo is: Lint evaluates each policy six
// times per peer, and an IXP lint's answers fill most of that (AS31117's 13
// filters weigh 1,928,317). The evaluator, and so the call's memo, lives for
// one call: Check makes one per side, Peers one, and Lint one for its
// sessions and one each for its peer list, set walk and router walk. Every
// evaluation consist makes goes through it.
func (c *Checker) eval() *peval.Evaluator {
	e := c.Eval
	e.Expander.Exclude = resolve.Exclusion{}
	switch {
	case e.Src == nil:
	case c.Memo != nil:
		e.Src = memoSource{PolicySource: e.Src, m: c.Memo}
		e.Expander.Memo = resolve.NewFilterMemoOver(c.Memo.filters, c.Memo.ranges)
	default:
		e.Src = &policyMemo{PolicySource: e.Src, autNums: map[policyKey]autNumAnswer{}, rtrs: map[policyKey]inetRtrAnswer{}}
		if e.Expander.Memo == nil {
			e.Expander.Memo = resolve.NewFilterMemo(defaultMemoRanges)
		}
	}
	return &e
}
```
