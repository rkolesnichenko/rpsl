# An IRRd-compatible Mirror Server (`rpsld`, v0.24.0) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Serve registries held in memory — from dumps, NRTMv4 mirrors and RPKI VRPs — over the IRRd query protocol and RIPE-style whois, answering as IRRd 4.5.3 answers, so bgpq4, IRRToolSet, `rpslq` and our own clients run against a local, current mirror unchanged.

**Architecture:**
- `resolve/irrdq` (pure, no `net`) holds IRRd's query semantics over an immutable `Snapshot` of per-registry indexes; `Session.Do` turns one command line into one `Reply`.
- `resolve/irrdserver` puts sessions on sockets with limits; `resolve/internal/rpsld` loads, refreshes and publishes snapshots; `resolve/cmd/rpsld` is the shim.
- Correctness is held to two oracles: `resolve/internal/irrtest` (in CI) and a real IRRd 4.5.3 in Docker, whose answers on a fixed fixture are recorded as goldens checked in CI and re-recorded with `RPSL_IRRD_DOCKER=1`.

**Tech Stack:** Go 1.23 floor, standard library only (`log/slog`, `net`, `os/signal`, `sync/atomic`). Multi-module repo (`go.work`); everything new is in the `resolve` module. Docker (Compose v2) for the IRRd oracle only, never on the host.

**Spec:** `docs/superpowers/specs/2026-10-02-irrd-server-design.md` — read it first; this plan argues from it. Where this plan refines the spec (marked **Refinement**), the plan wins and Task 12 updates the spec's text.

## Global Constraints

- Go floor `go 1.23` in every go.mod; standard library only; no new dependencies.
- Engine purity: `cd resolve && go list -deps . ./peval ./rtconfig ./consist ./irrdq | grep -x net` prints nothing.
- `resolve/internal/irrtest` stays independent: `irrdq` never imports it (tests may), and it never imports `irrdq` or `irrdserver`.
- IRRd's semantics live in `irrdq`, never in `resolve.Expander`; RFC mode calls the engine unchanged.
- Errors are values; nothing panics on hostile input; every limit refuses with IRRd's `F` and a reason, never a truncated answer.
- A class or route text the mirror does not keep is refused with `F`, never answered as not found.
- One answer, one snapshot: `Session.Do` reads the snapshot once per command.
- Output a person or a test compares is deterministic: no map-order dependence.
- Never install software on the host; Docker containers are fine.
- Commit messages follow the repository's style: `resolve: …`, `irrdq: …`, `irrdserver: …`, `rpsld: …`, `docs: …`. Stage by path, never `git add -A`.
- Each task's implementer runs only the packages it touches (`go test ./<pkg>`, `go vet`, `gofmt -l`); the controller runs `scripts/check.sh` in a separate worktree. Concurrent full suites exhaust local ports (`can't assign requested address`); that is environmental.
- Resolve-module tests that read a file outside `resolve/` skip when `../../go.work` is absent (release.sh step 6 tests the published module), and fail inside the checkout when the file is missing.

## Refinements to the spec

Each is stated in full in the task that makes it; Task 12 folds them into the spec.

1. The Docker oracle records a fixed fixture once; random IRRs are held to `irrtest` (Task 2).
2. IRRd's unordered answers (`!g`, `!6`, `!a`, `!r …,o`, multi-object answers) are compared as multisets; `rpsld` sorts them (Tasks 2, 5).
3. Object text is served as loaded, not re-rendered as IRRd renders it — the user's decision of 2026-10-02 (Task 2).
4. One listener for IRRd and RIPE-style queries, as IRRd 4 has; no `ServeWhois`, no `-whois-listen` (Task 4).
5. `!v` answers `IRRd -- version 4.5.3 (rpsld <version>)` (Task 4).
6. `!j` answers `NAME:N:0-<serial>`, `NAME:N:-` for serial 0 (Task 4).
7. `!s-*` changes nothing and `q` is a query, as in IRRd 4.5.3 (Task 4).
8. `!g`, `!6`, `!a` sorted IPv4 first, by address, then length (Task 5).
9. `!r` answers objects by default and origins with `o`; objects need route text (Task 6).
10. The RIPE-style flags served, and the IRRd commands not served (Task 6).
11. What the mirror does not keep is refused, with the exact texts (Task 6).
12. `!m` accepts IRRToolSet's legacy class names (Task 6).
13. The limits' defaults; IRRd queues past its connection limit and has no line limit (Task 8).
14. `-rpki-default`, `-check-dumps`, `-nrtm-interval` (Task 10).

## Review Focus

1. **One answer, one snapshot.** While registries swap, a reply never mixes two snapshots' data. Pinned in Task 8 (`TestAnswersComeFromOneSnapshot`, under `-race`) and by `Session.Do`'s contract (Task 4, `TestSnapshotReadOncePerCommand`).
2. **What is not kept is refused, never "not found".** `!mmntner,…`, `-T person`, `-i mnt-by`, a lookup of a key that could name a person, and route text without `-keep-route-text`. Pinned in Task 6 (`diverges`, `TestRouteTextNotKept`).
3. **IRRd mode never leaks the engine's semantics, and RFC mode changes only `!i…,1` and `!a`.** Pinned by the goldens (Tasks 4-7) and Task 7's `TestRFCMode` (its loop over other commands).
4. **A failed sync or reload keeps the previous registry and its serial.** Pinned in Task 10 (`TestServesAndReloadsDumps` removes the dump; `TestMirrorsNRTMv4` fails every sync).
5. **Every limit refuses with `F`; nothing is truncated; nothing panics.** Pinned in Task 8 (`TestLimits`, `TestQueryTime`, `TestMaxConns`, `TestStuckClient`) and `FuzzSession`.

  ```go
      Origin types.ASN
  ```

A `Corpus` keeps a route that claims nothing as `routeKey{prefix, origin, source}` only. The server (Task 4 onwards) must answer `!m route`, `!r …,o` and whois `-i origin` with the route's text, so `KeepRouteText` keeps it beside the key, in its own map (`routeText`), allocated only when the flag is set: a corpus without it costs nothing more than today (`TestCorpusMemory` must stay green unchanged). `Routes` is how the server reads every route a corpus holds — reduced and whole — without a `MemSource` round trip; the order is unspecified (callers sort). `Whole` yields the objects kept whole — every set and every member-of claimant — which the server's inverse queries (`-i member-of`, `-i members`, `-i mbrs-by-ref`) search; text-kept aut-nums and inet-rtrs are not among them (they claim nothing).

```go
// keepText holds o's text, from its first attribute line, for the reduced
// route rk. An object built by hand has no text and keeps none.
func (c *Corpus) keepText(rk routeKey, o object.Object) {
	raw := o.Raw()
	if raw == nil {
		delete(c.routeText, rk)
		return
	}
	if c.routeText == nil {
		c.routeText = map[routeKey]string{}
	}
	c.routeText[rk] = strings.Clone(textFrom(raw))
}
```

```go
	for rk := range other.routes {
		text := other.routeText[rk]
		rk.source = c.intern(rk.source)
		delete(c.whole, wholeKey{routeClass(rk.prefix), rk.pk(), rk.source})
```

```go
// CorpusRoute is one route or route6 a Corpus holds.
type CorpusRoute struct {
	Prefix netip.Prefix // as routeOf gives it
	Origin types.ASN
	Source string // upper-case
	Text   string // from the first attribute line; "" when not kept (KeepRouteText)
}

// Routes yields every route and route6 the corpus holds with a valid prefix
// and origin: each reduced one (with its text when KeepRouteText kept it)
// and each kept whole as a member-of claimant (with its text always). The
// order is unspecified.
func (c *Corpus) Routes() iter.Seq[CorpusRoute] {
	return func(yield func(CorpusRoute) bool) {
		for rk := range c.routes {
			if !yield(CorpusRoute{rk.prefix, rk.origin, rk.source, c.routeText[rk]}) {
				return
			}
		}
		for _, h := range c.whole {
			if h.obj == nil || (h.key.class != "route" && h.key.class != "route6") {
				continue
			}
			p, origin, ok := routeOf(h.obj)
			if !ok {
				continue
			}
			var text string
			if raw := h.obj.Raw(); raw != nil {
				text = textFrom(raw)
			}
			if !yield(CorpusRoute{p, origin, h.key.source, text}) {
				return
			}
		}
	}
}
```

The spike that settled this plan ran IRRd 4.5.3 in Docker and recorded its answers; this task makes that repeatable and checks the answers in, so every later task — and CI — is held to what IRRd actually does without running it. The fixture and Docker files below are the spike's, verbatim except where noted; IRRd refuses some RPSL our library accepts (`191.243.44/22`, an rtr-set `mp-members:` address), and its loader aborts on the first bad object, so the fixture holds only objects IRRd accepts.

**Refinement 1.** The spec's Docker oracle was to load random IRRs as well. IRRd's loader rejects whole files on one object it refuses (the random generators write RPSL that only our library accepts), so the Docker oracle checks this fixed fixture, recorded once; random IRRs are held to `irrtest`, which Task 3 corrects against these recordings.

**Refinement 2.** IRRd answers `!g`, `!6`, `!a` in hash order (the same query gave two orders across a restart) and multi-object answers in database order. Those cases are `Words` or `Objects`: compared as multisets. Our server sorts them (Task 5).

```go
// Package irrdoracle holds what a real IRRd 4.5.3 answered on a fixed fixture
// (resolve/testdata/irrd): the cases, their recorded answers (goldens), and
// how to compare another server's answer with one. TestRecord re-records the
// goldens from IRRd in Docker when RPSL_IRRD_DOCKER=1; every other test reads
// them, so CI holds irrtest (Task 3) and irrdq (Tasks 4-7) to IRRd without
// running it.
//
// It is a test helper: only _test.go files import it, and it imports neither
// irrdq nor irrtest, so it can judge both.
package irrdoracle

import (
	"bufio"
	"fmt"
	"net/netip"
	"os"
	"path/filepath"
	"runtime"
	"slices"
	"strconv"
	"strings"
	"testing"

	"github.com/rkolesnichenko/rpsl"
	"github.com/rkolesnichenko/rpsl/types"
)

// Kind is how an answer is compared.
type Kind int

const (
	Exact   Kind = iota // the bytes must be equal
	Words               // each A-frame's payload compared as a multiset of words
	Objects             // each reply compared as a multiset of objects (Normalize)
)

func (k Kind) String() string { return [...]string{"exact", "words", "objects"}[k] }

// Case is one exchange: what is sent on a fresh connection, under which
// IRRd configuration ("plain" or "rpki"), and how its answer is compared.
type Case struct {
	Name   string
	Config string
	Send   string
	Kind   Kind
}

// Golden is a case with what IRRd answered: every byte it wrote until it
// closed the connection, or until two seconds passed without a byte.
type Golden struct {
	Case
	Got string
}

// Fixture returns the fixture directory, resolve/testdata/irrd.
func Fixture(t testing.TB) string {
	t.Helper()
	_, file, _, ok := runtime.Caller(0)
	if !ok {
		t.Fatal("irrdoracle: no caller")
	}
	return filepath.Join(filepath.Dir(file), "..", "..", "testdata", "irrd")
}

// The golden file format, one record per case:
//
//	=== <name> <kind>
//	>>> <Send, strconv.Quote>
//	<<< <Got, strconv.Quote>

// Load reads golden/<config>.txt.
func Load(t testing.TB, config string) []Golden {
	t.Helper()
	path := filepath.Join(Fixture(t), "golden", config+".txt")
	f, err := os.Open(path)
	if err != nil {
		t.Fatal(err)
	}
	defer f.Close()
	var out []Golden
	sc := bufio.NewScanner(f)
	sc.Buffer(make([]byte, 1<<20), 16<<20)
	var g Golden
	for sc.Scan() {
		line := sc.Text()
		switch {
		case strings.HasPrefix(line, "=== "):
			name, kind, _ := strings.Cut(line[4:], " ")
			g = Golden{Case: Case{Name: name, Config: config}}
			switch kind {
			case "exact":
				g.Kind = Exact
			case "words":
				g.Kind = Words
			case "objects":
				g.Kind = Objects
			default:
				t.Fatalf("%s: case %s: kind %q", path, name, kind)
			}
		case strings.HasPrefix(line, ">>> "):
			s, err := strconv.Unquote(line[4:])
			if err != nil {
				t.Fatalf("%s: case %s: %v", path, g.Name, err)
			}
			g.Send = s
		case strings.HasPrefix(line, "<<< "):
			s, err := strconv.Unquote(line[4:])
			if err != nil {
				t.Fatalf("%s: case %s: %v", path, g.Name, err)
			}
			g.Got = s
			out = append(out, g)
		}
	}
	if err := sc.Err(); err != nil {
		t.Fatal(err)
	}
	return out
}

// Write writes goldens in Load's format.
func Write(path string, gs []Golden) error {
	var b strings.Builder
	for _, g := range gs {
		fmt.Fprintf(&b, "=== %s %s\n>>> %s\n<<< %s\n", g.Name, g.Kind, strconv.Quote(g.Send), strconv.Quote(g.Got))
	}
	return os.WriteFile(path, []byte(b.String()), 0o644)
}

// Split cuts an answer stream into replies: an IRRd frame (A<len>, its
// payload and its C line), a bare C, D or E line, an F line, or a RIPE-style
// answer (objects or a % line) ending in two blank lines. A frame is cut by
// its length, so a payload holding blank lines stays whole.
func Split(b string) []string {
	var out []string
	for len(b) > 0 {
		nl := strings.IndexByte(b, '\n')
		if nl < 0 {
			return append(out, b) // a fragment: kept as it is, to fail any comparison
		}
		line := b[:nl]
		switch {
		case len(line) > 1 && line[0] == 'A' && isDigits(line[1:]):
			n, _ := strconv.Atoi(line[1:])
			end := nl + 1 + n
			if end > len(b) {
				return append(out, b)
			}
			if c := strings.IndexByte(b[end:], '\n'); c >= 0 {
				end += c + 1
			} else {
				end = len(b)
			}
			out = append(out, b[:end])
			b = b[end:]
		case line == "C" || line == "D" || line == "E" || strings.HasPrefix(line, "F ") || line == "F":
			out = append(out, b[:nl+1])
			b = b[nl+1:]
		default:
			end := strings.Index(b, "\n\n\n")
			if end < 0 {
				return append(out, b)
			}
			out = append(out, b[:end+3])
			b = b[end+3:]
		}
	}
	return out
}

func isDigits(s string) bool {
	for _, c := range s {
		if c < '0' || c > '9' {
			return false
		}
	}
	return s != ""
}

// Compare reports how got differs from want under k, or nil.
func Compare(k Kind, got, want string) error {
	if k == Exact {
		if got != want {
			return fmt.Errorf("got %q\nwant %q", got, want)
		}
		return nil
	}
	g, w := Split(got), Split(want)
	if len(g) != len(w) {
		return fmt.Errorf("%d replies, want %d:\n got %q\nwant %q", len(g), len(w), got, want)
	}
	for i := range g {
		var a, b []string
		if k == Words {
			a, b = words(g[i]), words(w[i])
		} else {
			a, b = objects(g[i]), objects(w[i])
		}
		slices.Sort(a)
		slices.Sort(b)
		if !slices.Equal(a, b) {
			return fmt.Errorf("reply %d differs:\n got %q\nwant %q", i, g[i], w[i])
		}
	}
	return nil
}

// words is a frame's payload as words, or the reply itself as one word.
func words(r string) []string {
	if p, ok := payload(r); ok {
		return strings.Fields(p)
	}
	return []string{r}
}

// payload is an A-frame's payload.
func payload(r string) (string, bool) {
	nl := strings.IndexByte(r, '\n')
	if nl < 0 || r[0] != 'A' || !isDigits(r[1:nl]) {
		return "", false
	}
	n, _ := strconv.Atoi(r[1:nl])
	if nl+1+n > len(r) {
		return "", false
	}
	return r[nl+1 : nl+1+n], true
}

// objects is a reply's objects, each Normalized; a reply holding none (C, D,
// F, a % line) is itself.
func objects(r string) []string {
	text, ok := payload(r)
	if !ok {
		if r == "C\n" || r == "D\n" || r == "E\n" || r == "F\n" || strings.HasPrefix(r, "F ") || strings.HasPrefix(r, "%") {
			return []string{r} // a status line or a % message: compared whole
		}
		text = strings.TrimSuffix(r, "\n\n")
	}
	var out []string
	for _, o := range strings.Split(strings.Trim(text, "\n"), "\n\n") {
		if o != "" {
			out = append(out, Normalize(o+"\n"))
		}
	}
	return out
}

// Normalize returns an object's canonical form for comparison: one line per
// attribute, its name lower-case, its value as the lexer folds it (comments
// stripped, continuation lines joined), every run of whitespace one space,
// no space after a comma; list attributes item by item; a route's or
// route6's key, and a route-set's prefix members, as netip prints them
// (zero padding gone, a bare address given its host length). These are the
// rewrites IRRd makes when it serves an object, so an object as loaded and
// as IRRd serves it normalize alike.
func Normalize(objText string) string {
	o, _ := rpsl.ParseObject(objText)
	if o == nil || len(o.Attributes()) == 0 {
		return objText
	}
	class := strings.ToLower(o.Class())
	var b strings.Builder
	for i, a := range o.Attributes() {
		name := strings.ToLower(a.Name)
		var items []string
		for _, it := range a.List() {
			v := strings.Join(strings.Fields(it.Value), " ")
			if i == 0 && (class == "route" || class == "route6") {
				v = canonPrefix(v)
			}
			if class == "route-set" && (name == "members" || name == "mp-members") {
				v = canonMember(v)
			}
			items = append(items, v)
		}
		fmt.Fprintf(&b, "%s:%s\n", name, strings.Join(items, ","))
	}
	return b.String()
}

func canonPrefix(s string) string {
	if p, err := types.ParsePrefix(s); err == nil {
		return p.String()
	}
	return s
}

func canonMember(s string) string {
	base, op, hasOp := strings.Cut(s, "^")
	if p, err := types.ParsePrefix(base); err == nil {
		base = p.String()
	} else if a, err := types.ParseAddr(base); err == nil {
		base = netip.PrefixFrom(a, a.BitLen()).String()
	}
	if hasOp {
		return base + "^" + op
	}
	return base
}
```

```go
// TestRecord starts IRRd 4.5.3 in Docker on the fixture, once per
// configuration, asks it every case on a fresh connection and rewrites
// golden/<config>.txt. Opt-in: RPSL_IRRD_DOCKER=1 (Docker and Compose v2;
// nothing is installed on the host). About two minutes the first time (the
// image builds), a few seconds per configuration after.
func TestRecord(t *testing.T) {
	if os.Getenv("RPSL_IRRD_DOCKER") != "1" {
		t.Skip("set RPSL_IRRD_DOCKER=1 to record IRRd's answers in Docker")
	}
	dir := Fixture(t)
	run := func(args ...string) {
		cmd := exec.Command(filepath.Join(dir, "run.sh"), args...)
		cmd.Stdout, cmd.Stderr = os.Stderr, os.Stderr
		if err := cmd.Run(); err != nil {
			t.Fatalf("run.sh %v: %v", args, err)
		}
	}
	t.Cleanup(func() { run("down") })
	for _, config := range []string{"plain", "rpki"} {
		run("up", config)
		var gs []Golden
		for _, c := range Cases() {
			if c.Config != config {
				continue
			}
			gs = append(gs, Golden{Case: c, Got: ask(t, "127.0.0.1:18043", c.Send)})
		}
		if err := Write(filepath.Join(dir, "golden", config+".txt"), gs); err != nil {
			t.Fatal(err)
		}
		run("down")
	}
}

// ask sends send on a fresh connection and returns every byte answered until
// the server closes it or two seconds pass without one.
func ask(t *testing.T, addr, send string) string {
	t.Helper()
	c, err := net.DialTimeout("tcp", addr, 5*time.Second)
	if err != nil {
		t.Fatal(err)
	}
	defer c.Close()
	if _, err := c.Write([]byte(send)); err != nil {
		t.Fatal(err)
	}
	var out []byte
	buf := make([]byte, 64<<10)
	for {
		c.SetReadDeadline(time.Now().Add(2 * time.Second))
		n, err := c.Read(buf)
		out = append(out, buf[:n]...)
		if err != nil {
			return string(out)
		}
	}
}
```

`irrtest` was written from IRRd's documentation and code reading; the recordings show where it is wrong. It is the oracle every random-IRR test (expansion models, bgpq4, IRRToolSet, and from Task 5 `irrdq` itself) is held to, so it is corrected before `irrdq` is written. Its separate `Whois(t)` listener models the RIPE Database's whois server (banner, `%ERROR:101`) for `whois.Source`'s tests and is not IRRd: it is left as it is; only the IRRd port (`IRRd(t)`) is held to the goldens.

What the recordings showed `irrtest` gets wrong on the IRRd port (the spike's findings; each is a `TestMatchesIRRd` failure until fixed):

1. **`!i<set>,1` drops every unresolved leaf.** IRRd's `_recursive_set_resolve` returns only resolved members: a missing set, `AS-ANY`, a route-set reached from an as-set root, a member with a range operator (`RS-INNER^25`, `AS65002^24` are looked up as set names, found nowhere, and dropped), and a prefix member of an as-set are all left out. `!iAS-FOO,1` is `AS65001 AS65002 AS65003`, not that plus `AS-ANY AS-MISSING RS-INNER`.
2. **`!s-*` changes nothing** in IRRd 4.5.3: after `!sRIPE`, `!s-*`, `!s-lc` still answers `RIPE`. It is answered `C`.
3. **`q` is not a quit command**; it is a RIPE-style query for the text `q`, answered `%  No entries found for the selected source(s).\n\n\n`. Only `!q` (and `!Q`) closes.
4. **`!a` on an as-set that resolves to no prefixes is `D`**, not `C`.
5. **`!i` members are normalized, sorted and distinct**: IRRd answers its parsed values (`AS65001` for `as65001`; a route-set's bare address with its host length; comments and continuation lines gone), sorted as strings, each once.
6. **Error texts.** `!g`/`!6` with a bad AS: `F Invalid AS number 65001: must start with "AS"`, `F Invalid AS number AS1.10: number part is not numeric`, `F Invalid AS number AS4294967296: valid range is 0-4294967295`; a missing argument: `F Missing parameter for g query` (and `i`, `s`, `j`, `n`, `t`, `m` alike); an unknown command: `F Unrecognised command: x`; `!` alone: `F Missing IRRD command`; a NUL byte anywhere in the line: `F Queries may not contain null bytes`. Use the goldens' exact text.
7. **`!v`** is `IRRd -- version 4.5.3` (IRRToolSet needs the word "version"; keep it).
8. **`!m`** matches the class name case-sensitively (`!mAUT-NUM,AS65001` is `D`); a route key may hold spaces or a `-` between prefix and origin and a lower-case `as` (`192.0.2.0/24 AS65001`, `192.0.2.0/24-AS65001`, `192.0.2.0/24as65001`), but its prefix must be written canonically (`2001:0db8::/32AS65001` and `064.006.160.000/19AS65007` are `D`); a lower-case IPv6 prefix in upper case is accepted (`2001:DB8::/32AS65001`). Legacy class names (`an`, `ir`, `rt`) stay behind `WithLegacyClasses` (IRRd 4.5.3 answers them `D`; IRRToolSet's `rtconfig` needs them).
9. **RIPE-style answers on the IRRd port**: one query per connection unless `!!` was sent or the query carries `-k`; `-B` and `-G` are errors (`%% ERROR: Unrecognised flag/search: B`); `-K` lists the primary key attributes and every `members:` and `mp-members:` item, one per line, distinct; an unknown source is `%% ERROR: One or more selected sources are unavailable.\n\n\n`; an `-s` inside a session changes the session's selection for good (golden `ripe/s-flag-sticks`).

```go
package irrdq

import (
	"fmt"
	"net/netip"
	"slices"

	"github.com/rkolesnichenko/rpsl/resolve"
	"github.com/rkolesnichenko/rpsl/resolve/rpki"
	"github.com/rkolesnichenko/rpsl/types"
)

// A Registry is one source's data, immutable once built.
type Registry struct {
	name     string
	serial   uint64
	src      *resolve.MemSource      // sets, claims, aut-nums, inet-rtrs, routes by origin
	routes   []route                 // every route and route6, sorted (routeLess)
	byPrefix map[netip.Prefix][]int // exact prefix -> indexes into routes
	text     bool                    // route text kept (Corpus.KeepRouteText)
}

// route is one route or route6 object of a registry.
type route struct {
	prefix netip.Prefix
	origin types.ASN
	text   string // "" unless kept
}

// NewRegistry builds a registry named name (an IRR source name, canonical
// upper-case) from the objects of c whose source: is name; c's objects of
// other sources are left out. c must keep policy (Corpus.KeepPolicy or
// IndexPeers): a registry answers "!maut-num" and "!minet-rtr", and a
// corpus that dropped its aut-nums would answer them "not found".
func NewRegistry(name string, serial uint64, c *resolve.Corpus) (*Registry, error) {
	n, err := types.ParseSourceName(name)
	if err != nil {
		return nil, fmt.Errorf("irrdq: registry %q: %w", name, err)
	}
	if !c.KeepPolicy && !c.IndexPeers {
		return nil, fmt.Errorf("irrdq: registry %s: its Corpus must keep policy (KeepPolicy)", n)
	}
	r := &Registry{name: n, serial: serial, src: c.SourceOf(n), text: c.KeepRouteText, byPrefix: map[netip.Prefix][]int{}}
	for cr := range c.Routes() {
		if cr.Source == n {
			r.routes = append(r.routes, route{cr.Prefix, cr.Origin, cr.Text})
		}
	}
	slices.SortFunc(r.routes, routeCmp)
	for i, rt := range r.routes {
		r.byPrefix[rt.prefix] = append(r.byPrefix[rt.prefix], i)
	}
	return r, nil
}

// routeCmp orders routes IPv4 first, then by address, length and origin.
func routeCmp(a, b route) int {
	if c := prefixCmp(a.prefix, b.prefix); c != 0 {
		return c
	}
	switch {
	case a.origin < b.origin:
		return -1
	case a.origin > b.origin:
		return 1
	}
	return 0
}

// prefixCmp orders prefixes IPv4 first, then by address, then length.
func prefixCmp(a, b netip.Prefix) int {
	if a.Addr().Is4() != b.Addr().Is4() {
		if a.Addr().Is4() {
			return -1
		}
		return 1
	}
	if c := a.Addr().Compare(b.Addr()); c != 0 {
		return c
	}
	return a.Bits() - b.Bits()
}

func (r *Registry) Name() string         { return r.name }
func (r *Registry) Serial() uint64       { return r.serial }
func (r *Registry) KeepsRouteText() bool { return r.text }

// SnapshotOptions configures a Snapshot.
type SnapshotOptions struct {
	// Default is the registries a session selects until it sends "!s", in
	// precedence order — IRRd's sources_default. nil: every registry, in
	// order.
	Default []string
	// VRPs puts the snapshot in IRRd 4's RPKI-aware mode (Task 7).
	VRPs *rpki.VRPs
	// RFC answers "!i…,1" and "!a" by resolve.Expander (Task 7).
	RFC bool
	// Expander holds the limits for RFC mode; its Src is set per query.
	Expander resolve.Expander
	// Version follows "IRRd -- version 4.5.3" in the "!v" answer, in
	// parentheses after "rpsld"; "" leaves just "rpsld".
	Version string
}

// A Snapshot is everything one answer is computed from: registries in
// precedence order and the options. It is immutable.
type Snapshot struct {
	regs   []*Registry
	byName map[string]*Registry
	dflt   []string
	opts   SnapshotOptions
}

// NewSnapshot builds a snapshot of regs, which must have distinct names.
func NewSnapshot(regs []*Registry, opts SnapshotOptions) (*Snapshot, error) {
	s := &Snapshot{regs: slices.Clone(regs), byName: map[string]*Registry{}, opts: opts}
	for _, r := range regs {
		if s.byName[r.name] != nil {
			return nil, fmt.Errorf("irrdq: two registries named %s", r.name)
		}
		s.byName[r.name] = r
	}
	if opts.Default == nil {
		for _, r := range regs {
			s.dflt = append(s.dflt, r.name)
		}
	} else {
		for _, d := range opts.Default {
			n, err := types.ParseSourceName(d)
			if err != nil || s.byName[n] == nil {
				return nil, fmt.Errorf("irrdq: default source %q is no registry", d)
			}
			s.dflt = append(s.dflt, n)
		}
	}
	return s, nil
}

// With returns a snapshot whose registry of r's name is r; s is unchanged.
func (s *Snapshot) With(r *Registry) (*Snapshot, error) {
	if s.byName[r.name] == nil {
		return nil, fmt.Errorf("irrdq: no registry %s to replace", r.name)
	}
	regs := slices.Clone(s.regs)
	for i := range regs {
		if regs[i].name == r.name {
			regs[i] = r
		}
	}
	opts := s.opts
	opts.Default = s.dflt
	return NewSnapshot(regs, opts)
}

// Registries returns the registries in precedence order.
func (s *Snapshot) Registries() []*Registry { return slices.Clone(s.regs) }

// selected returns the registries of names, in that order.
func (s *Snapshot) selected(names []string) []*Registry {
	out := make([]*Registry, 0, len(names))
	for _, n := range names {
		if r := s.byName[n]; r != nil {
			out = append(out, r)
		}
	}
	return out
}
```

```go
// parseAS reads an AS number as IRRd's parse_as_number does: "AS" (either
// case) then decimal digits, at most 4294967295. msg is IRRd's error text.
func parseAS(s string) (as types.ASN, msg string) {
	if len(s) < 2 || !strings.EqualFold(s[:2], "AS") {
		return 0, "Invalid AS number " + s + `: must start with "AS"`
	}
	digits := s[2:]
	if digits == "" || strings.Trim(digits, "0123456789") != "" {
		return 0, "Invalid AS number " + s + ": number part is not numeric"
	}
```

```go
// A Reply is what the server writes for one command, and whether the
// connection closes after it.
type Reply struct {
	text  string
	close bool
}

func (r Reply) WriteTo(w io.Writer) (int64, error) {
	n, err := io.WriteString(w, r.text)
	return int64(n), err
}
func (r Reply) Close() bool { return r.close }
func (r Reply) Len() int    { return len(r.text) }

// frame is IRRd's data answer: "A<len>", the payload and a newline (counted
// in len), then "C".
func frame(payload string) Reply {
	payload += "\n"
	return Reply{text: fmt.Sprintf("A%d\n%sC\n", len(payload), payload)}
}

	notFound = Reply{text: "D\n"}
	nothing  = Reply{}

// A Session is one client connection's state: its selected registries, its
// persistent mode, its timeout.

	sel        []string // nil: the snapshot's default
	persistent bool
	timeout    time.Duration
}

// NewSession starts a session that reads the current snapshot from snapshot,
// once per command.
func NewSession(snapshot func() *Snapshot) *Session { return &Session{snapshot: snapshot} }

func (s *Session) Timeout() time.Duration { return s.timeout }

	}
	return snap.dflt
}

// Do answers one command line (its "\n" already cut). A blank line is no
// command. Without "!!" the connection closes after the first command; "!q"
// closes it. The error is non-nil only when ctx ended; the reply then carries
// only whether the connection closes.
func (s *Session) Do(ctx context.Context, line string) (Reply, error) {
	line = strings.TrimRight(line, "\r")
	if strings.TrimSpace(line) == "" {
		return nothing, nil
	}
	snap := s.snapshot()
	r := s.do(ctx, snap, line)
	if !s.persistent && line != "!!" {
		r.close = true
	}
	// A reply cut short by ctx is not sent; its close flag is, through
	// Reply.Refused (resolve/irrdserver).
	return r, ctx.Err()
}

func (s *Session) do(ctx context.Context, snap *Snapshot, line string) Reply {
	if strings.IndexByte(line, 0) >= 0 {
		return Fail("Queries may not contain null bytes")
	}
	if line[0] != '!' {
		return s.ripe(ctx, snap, line)
	}
	if line == "!" {
		return Fail("Missing IRRD command")
	}
	cmd, arg := line[1], line[2:]
	switch cmd {
	case '!':
		s.persistent = true
		return nothing
	case 'q', 'Q':
		return Reply{close: true}
	case 'v':
		return frame("IRRd -- version 4.5.3 (rpsld" + suffix(snap.opts.Version) + ")")
	}
	if arg == "" {
		switch cmd {
		case 'a':
			return Fail("Missing required set name for A query")
		case 'i', 'g', '6', 's', 'j', 'n', 't', 'm', 'r':
			return Fail("Missing parameter for " + string(cmd) + " query")
		}
	}
	switch cmd {
	case 'n':
		return ok
	case 't':
		v, err := strconv.Atoi(arg)
		if err != nil || v < 1 || v > 1000 {
			return Fail("Invalid value for timeout: " + arg)
		}
		s.timeout = time.Duration(v) * time.Second
		return ok
	case 's':
		return s.selectSources(snap, arg)
	case 'j':
		return serials(snap, arg)
	}
	if h := commands[cmd]; h != nil {
		return h(ctx, s, snap, arg)
	}
	return Fail("Unrecognised command: " + string(cmd))
}
```

  The answer is every result, the root's name removed, sorted, each once; none is `D`. // normMember is one members:/mp-members: item as IRRd's parser stores it:
```go
// an AS number (an operator kept) upper-case and asplain, a prefix (an
// operator kept) as netip prints it, a bare address with its host length,
// anything else upper-case.
func normMember(item string) string {
	base, op, hasOp := strings.Cut(strings.TrimSpace(item), "^")
	switch {
	case isASN(base):
		as, _ := types.ParseASN(base)
		base = as.String()
	case strings.Contains(base, "/"):
		if p, err := types.ParsePrefix(base); err == nil {
			base = p.String()
		}
	default:
		if a, err := types.ParseAddr(base); err == nil {
			base = netip.PrefixFrom(a, a.BitLen()).String()
		} else {
			base = strings.ToUpper(base)
		}
	}
	if hasOp {
		return base + "^" + op
	}
	return base
}

// isASN reports whether s is an AS number as IRRd's parse_as_number reads
// one: "AS" then digits.
func isASN(s string) bool {
	_, msg := parseAS(s)
	return msg == ""
}

// setMembers returns the members of the set name — the first found among
// as-sets, then among route-sets (only as-sets when asOnly), in each of regs
// in order — and its class; found is false when no such set is held.
func (snap *Snapshot) setMembers(ctx context.Context, regs []*Registry, name string, asOnly bool) (members []string, class types.SetClass, found bool) {
	n, err := types.ParseSetName(name)
	if err != nil {
		return nil, 0, false
	}
	classes := []types.SetClass{types.ClassAsSet, types.ClassRouteSet}
	if asOnly {
		classes = classes[:1]
	}
	for _, want := range classes {
		if n.Class() != want {
			continue
		}
		for _, r := range regs {
			set, err := r.src.GetSet(ctx, types.Ref(n))
			if err != nil || set.Class() != want.String() {
				continue
			}
			return snap.membersOf(ctx, r, set), want, true
		}
	}
	return nil, 0, false
}

// membersOf is a set's members:/mp-members: items, normalized, and the
// primary keys of the objects mbrs-by-ref admits (ClaimAllowed: the set's
// own source, its maintainers): aut-nums for an as-set, routes and route6s
// (their prefixes) for a route-set.
func (snap *Snapshot) membersOf(ctx context.Context, r *Registry, set object.NamedSet) []string {

	if raw := set.Raw(); raw != nil {
		for _, attr := range []string{"members", "mp-members"} {
			for _, a := range raw.GetAll(attr) {
				for _, it := range a.List() {
					if it.Value != "" {
						out = append(out, normMember(it.Value))
					}
				}
			}
		}
	}
	claims, _ := snap.claimants(ctx, r, set)
	return append(out, claims...)
}

// recursive is IRRd's _recursive_set_resolve from the set name: see the
// task text. root fixes the root class (types.ClassAsSet for "!a"); 0 takes
// the first set found's.
func (snap *Snapshot) recursive(ctx context.Context, regs []*Registry, name string, root types.SetClass) []string {
	results := map[string]bool{}
	seen := map[string]bool{}
	level := []string{strings.ToUpper(name)}
	for len(level) > 0 && ctx.Err() == nil {
		for _, n := range level {
			seen[n] = true
		}
		var sub []string
		for _, n := range level {
			ms, class, found := snap.setMembers(ctx, regs, n, root == types.ClassAsSet)
			if !found {
				continue
			}
			if root == 0 {
				root = class
			}
			sub = append(sub, ms...)
		}
		var next []string
		for _, m := range sub {
			base, _, _ := strings.Cut(m, "^")
			if root == types.ClassRouteSet && isPrefixOrAddr(base) {
				results[m] = true
				continue
			}
			if isASN(m) {
				if root == types.ClassRouteSet {
					as, _ := parseAS(m)
					for _, p := range snap.originated(ctx, regs, as, 0) {
						results[p.String()] = true
					}
					seen[m] = true
				} else {
					results[m] = true
				}
				continue
			}
			if !results[m] && !seen[m] {
				next = append(next, m)
				seen[m] = true
			}
		}
		level = next
	}
	delete(results, strings.ToUpper(name))
	out := make([]string, 0, len(results))
	for m := range results {
		out = append(out, m)
	}
	slices.Sort(out)
	return out
}

func isPrefixOrAddr(s string) bool {
	if strings.Contains(s, "/") {
		_, err := types.ParsePrefix(s)
		return err == nil
	}
	_, err := types.ParseAddr(s)
	return err == nil
}

	var out []string
	if name, ok := strings.CutSuffix(arg, ",1"); ok {

	}

func (snap *Snapshot) recursiveOrRFC(ctx context.Context, regs []*Registry, name string) []string {

func distinctSorted(ms []string, drop string) []string {
	set := map[string]bool{}
	for _, m := range ms {
		if m != drop {
			set[m] = true
		}
	}
	out := make([]string, 0, len(set))
	for m := range set {
		out = append(out, m)
	}
	slices.Sort(out)
	return out
}

func (snap *Snapshot) asSetPrefixes(ctx context.Context, regs []*Registry, name string, afi types.AFI) []netip.Prefix {

		}
	}

}
```

**Refinement 9.** `!r` answers route *objects* by default and origins with `o` (the spec's table had it the other way): `l` is the most specific route strictly less specific than the prefix, `L` every less specific route and the exact one, `M` every more specific one (golden `r/…`). **Refinement 10.** RIPE-style flags served: `-s` (and it changes the connection's selection for good, as IRRd's does), `-T`, `-i` (`origin`, `member-of`, `mbrs-by-ref`, `members`, `mp-members`), `-K`, `-r`, `-k`, `-x`, `-l`, `-L`, `-M`. `-B`, `-G` and any other letter are IRRd's `%% ERROR: Unrecognised flag/search: <letter>` — IRRd 4.5.3 refuses `-B` and `-G` too. **Refinement 11.** What the mirror does not keep is refused, never "not found": `!m` of a known RPSL class outside the routing classes (`object.RIPE` or `object.IRRd` lists it) is `F Class <c> is not kept by this mirror`; `-T` naming one is `%% ERROR: Class <c> is not kept by this mirror`; `-i` on an attribute IRRd indexes but the mirror cannot answer whole (`mnt-by`, `admin-c`, `tech-c`, `zone-c`, `person`, `role`) is `%% ERROR: Inverse search on <attr> is not served by this mirror: it keeps the routing classes only`; a plain lookup of a key that is no AS number, set name, prefix or inet-rtr held — which could name a person, a maintainer or another class the mirror lacks — is `%% ERROR: This mirror keeps only the routing classes; it cannot answer a lookup of <key>`. **Refinement 12.** `!m` accepts IRRToolSet's legacy class names (`an`, `ir`, `rt`), which IRRd 4.5.3 answers `D`: IRRToolSet's `rtconfig` sends them and would get nothing. Pinned as a divergence.

What IRRd 4.5.3 does (the goldens):

- **`!m<class>,<key>`**: no comma is `F Invalid argument for object lookup: <arg>`; the class is matched case-sensitively; an empty or unknown key is `D`. Set and aut-num keys are case-insensitive; an inet-rtr's too. A route key may hold spaces or a `-` between prefix and origin and a lower-case `as`; its prefix must be canonical once lower-cased (`2001:0db8::/32` and `064.006.160.000/19` are `D`). The first selected registry that holds the object answers.
- **`!r<prefix>[,opt]`**: a prefix with host bits, an invalid one or a length out of range is `F Invalid input for route search: <arg>`; a bare address is its host prefix; an option other than `o`, `l`, `L`, `M` is `F Invalid route search option: <opt>`. Every selected registry contributes (no precedence); `o` lists one origin per object, duplicates kept.
- **RIPE-style**: answers end in two blank lines (`"…\n\n\n"`); objects are separated by one blank line; nothing is `%  No entries found for the selected source(s).`; an error is `%% ERROR: <msg>`. A missing flag argument is `%% ERROR: Missing argument for flag/search: <letter>`; a bad source `%% ERROR: One or more selected sources are unavailable.`. The key is the last word left after the flags (`AS65001 AS65002` looks up `AS65002`). A plain key looks up: a prefix or address, the exact routes; an AS number, the aut-num; a set name, that set in *every* selected registry; anything else, the inet-rtr of that name. `-K` writes each object's primary key attribute (`<class>: <key>`), `origin:` for a route, and each `members:`/`mp-members:` item (normalized) on its own line, as `<name>: <value>` with one space; identical key blocks from several registries are written once. `-i member-of` lists every object naming the set, without the mbrs-by-ref check (golden `ripe/-i member-of AS-REF` holds AS65002, maintained by MNT-B).

```go
// knownClass reports whether class is an RPSL class either profile lists.
func knownClass(class string) bool {
	_, ripe := object.RIPE.Class(class)
	_, irrd := object.IRRd.Class(class)
	return ripe || irrd

// objectText is raw's text from its first attribute line, ending in one
// newline: the object as the registry published it, without the blank or
// comment lines a dump stream put before it.
func objectText(raw *ast.Object) string {
	text := raw.String()
	rest, off := text, 0
	for len(rest) > 0 {
		line, eol := rest, len(rest)
		if nl := strings.IndexByte(rest, '\n'); nl >= 0 {
			line, eol = rest[:nl], nl+1
		}
		if lexer.StartsAttribute(strings.TrimSuffix(line, "\r")) {
			text = text[off:]
			break
		}
		off += eol
		rest = rest[eol:]
	}
	return strings.TrimRight(text, "\n") + "\n"
}

// parseRouteKey reads "!m route" keys as IRRd does: spaces and "-" removed,
// the origin after the last "AS" (either case), the prefix canonical once
// lower-cased.
func parseRouteKey(key string) (netip.Prefix, types.ASN, bool) {
	k := strings.NewReplacer(" ", "", "-", "").Replace(key)
	i := strings.LastIndex(strings.ToUpper(k), "AS") // ASCII only: offsets agree
	if i <= 0 || !isASCII(k) {
		return netip.Prefix{}, 0, false
	}
	pfx := strings.ToLower(k[:i])
	p, err := netip.ParsePrefix(pfx)
	if err != nil || p.String() != pfx {
		return netip.Prefix{}, 0, false
	}
	as, msg := parseAS(strings.ToUpper(k[i:]))
	return p, as, msg == ""
}

func isASCII(s string) bool {
	for i := 0; i < len(s); i++ {
		if s[i] >= 0x80 {
			return false
		}
	}
	return true

	class, key, found := strings.Cut(arg, ",")
	if !found {
		return Fail("Invalid argument for object lookup: " + arg)

	switch class { // IRRToolSet's legacy names (Refinement 12)
	case "an":
		class = "aut-num"
	case "ir":
		class = "inet-rtr"
	case "rt":
		class = "route"

	if !kept[class] {
		if knownClass(class) {
			return Fail("Class " + class + " is not kept by this mirror")
		}
		return notFound
	}
	if key == "" {
		return notFound
	}
	text, refused := snap.lookup(ctx, snap.selected(s.sources(snap)), class, key)
	switch {
	case refused != "":
		return Fail(refused)
	case text == "":
		return notFound
	}
	return frame(strings.TrimSuffix(text, "\n"))
}

// lookup is the text of the object of class and key in the first of regs
// that holds it, "" when none does; refused names why it cannot be served.
func (snap *Snapshot) lookup(ctx context.Context, regs []*Registry, class, key string) (text, refused string) {
	switch class {
	case "route", "route6":
		p, as, ok := parseRouteKey(key)
		if !ok || (class == "route") != p.Addr().Is4() {
			return "", ""
		}
		for _, r := range regs {
			for _, i := range r.byPrefix[p] {
				rt := r.routes[i]
				if rt.origin != as || !snap.visible(r, rt) {
					continue
				}
				if rt.text == "" {
					return "", textNotKept
				}
				return snap.routeText(r, rt), ""
			}
		}
	case "aut-num":
		as, err := types.ParseASN(key)
		if err != nil {
			return "", ""
		}
		for _, r := range regs {
			if an, err := r.src.AutNum(ctx, as, ""); err == nil && an.Raw() != nil {
				return objectText(an.Raw()), ""
			}
		}
	case "inet-rtr":
		for _, r := range regs {
			if rtr, err := r.src.InetRtr(ctx, key, ""); err == nil && rtr.Raw() != nil {
				return objectText(rtr.Raw()), ""
			}
		}
	default: // the set classes
		n, err := types.ParseSetName(key)
		if err != nil || n.Class().String() != class {
			return "", ""
		}
		for _, r := range regs {
			if set, err := r.src.GetSet(ctx, types.Ref(n)); err == nil && set.Class() == class && set.Raw() != nil {
				return objectText(set.Raw()), ""
			}
		}
	}
	return "", ""
}

// hit is a route of a registry.
type hit struct {
	reg *Registry
	rt  route
}

// parseSearchPrefix reads "!r"'s prefix: a canonical prefix (host bits are
// refused) or an address, its host prefix.
func parseSearchPrefix(s string) (netip.Prefix, bool) {
	s = strings.ToLower(s)
	if strings.Contains(s, "/") {
		p, err := netip.ParsePrefix(s)
		if err != nil || p.Masked() != p {
			return netip.Prefix{}, false
		}
		return p, true
	}
	a, err := netip.ParseAddr(s)
	if err != nil {
		return netip.Prefix{}, false
	}
	return netip.PrefixFrom(a, a.BitLen()), true
}

// search is the visible routes of regs that mode (0 exact, 'l', 'L', 'M')
// selects for p, in regs' order, each registry's sorted.
func (snap *Snapshot) search(regs []*Registry, p netip.Prefix, mode byte) []hit {
	var out []hit
	for _, r := range regs {
		add := func(i int) {
			if rt := r.routes[i]; snap.visible(r, rt) {
				out = append(out, hit{r, rt})
			}
		}
		switch mode {
		case 0:
			for _, i := range r.byPrefix[p] {
				add(i)
			}
		case 'L', 'l':
			var lens []int
			for bits := p.Bits(); bits >= 0; bits-- {
				if mode == 'l' && bits == p.Bits() {
					continue
				}
				q, _ := p.Addr().Prefix(bits)
				if len(r.byPrefix[q]) > 0 {
					lens = append(lens, bits)
				}
			}
			for _, bits := range lens {
				q, _ := p.Addr().Prefix(bits)
				for _, i := range r.byPrefix[q] {
					add(i)
				}
				if mode == 'l' {
					break // the most specific less specific prefix only
				}
			}
		case 'M':
			for i, rt := range r.routes {
				if rt.prefix.Addr().Is4() == p.Addr().Is4() && rt.prefix.Bits() > p.Bits() && p.Contains(rt.prefix.Addr()) {
					add(i)
				}
			}
		}
	}
	return out
}

func cmdRouteSearch(ctx context.Context, s *Session, snap *Snapshot, arg string) Reply {
	pfx, opt, _ := strings.Cut(arg, ",")
	p, ok := parseSearchPrefix(pfx)
	if !ok {
		return Fail("Invalid input for route search: " + pfx)
	}
	var mode byte
	switch opt {
	case "", "o":
	case "l", "L", "M":
		mode = opt[0]
	default:
		return Fail("Invalid route search option: " + opt)
	}
	hits := snap.search(snap.selected(s.sources(snap)), p, mode)
	if len(hits) == 0 {
		return notFound
	}
	if opt == "o" {
		words := make([]string, len(hits))
		for i, h := range hits {
			words[i] = h.rt.origin.String()
		}
		return frame(strings.Join(words, " "))
	}
	texts, refused := snap.texts(hits)
	if refused != "" {
		return Fail(refused)
	}
	return frame(strings.TrimSuffix(strings.Join(texts, "\n"), "\n"))
}

// texts is each hit's text as served, or why it cannot be served.
func (snap *Snapshot) texts(hits []hit) ([]string, string) {
	out := make([]string, 0, len(hits))
	for _, h := range hits {
		if h.rt.text == "" {
			return nil, textNotKept
		}
		out = append(out, snap.routeText(h.reg, h.rt))
	}
	return out, ""
}
```

```go
const noEntries = "%  No entries found for the selected source(s).\n\n\n"

func ripeError(msg string) Reply { return Reply{text: "%% ERROR: " + msg + "\n\n\n"} }

// inverseServed are the -i attributes the mirror answers whole.
var inverseServed = []string{"origin", "member-of", "mbrs-by-ref", "members", "mp-members"}

// inverseNotServed are the -i attributes IRRd indexes that the mirror
// cannot answer whole: they name objects of classes it does not keep.
var inverseNotServed = map[string]bool{"mnt-by": true, "admin-c": true, "tech-c": true, "zone-c": true, "person": true, "role": true}

// ripe answers a RIPE-style query (no "!").
func (s *Session) ripe(ctx context.Context, snap *Snapshot, line string) Reply {
	var (
		classes  []string
		inverse  string
		keysOnly bool
		mode     byte
		words    []string
	)
	toks := strings.Fields(line)
	for i := 0; i < len(toks); i++ {
		tok := toks[i]
		if len(tok) < 2 || tok[0] != '-' {
			words = append(words, tok)
			continue
		}
		for _, f := range tok[1:] {
			switch f {
			case 's', 'T', 'i':
				if i+1 >= len(toks) {
					return ripeError("Missing argument for flag/search: " + string(f))
				}
				i++
				switch f {
				case 's':
					var sel []string
					for _, n := range strings.Split(toks[i], ",") {
						name, err := types.ParseSourceName(n)
						if err != nil || snap.byName[name] == nil {
							return ripeError("One or more selected sources are unavailable.")
						}
						sel = append(sel, name)
					}
					s.sel = sel // IRRd keeps it for the connection (golden ripe/s-flag-sticks)
				case 'T':
					classes = strings.Split(strings.ToLower(toks[i]), ",")
				case 'i':
					inverse = strings.ToLower(toks[i])
					if i+1 >= len(toks) {
						return ripeError("Missing argument for flag/search: i")
					}
				}
			case 'K':
				keysOnly = true
			case 'k':
				s.persistent = true
			case 'r':
			case 'x', 'l', 'L', 'M':
				mode = byte(f)
			default:
				return ripeError("Unrecognised flag/search: " + string(f))
			}
		}
	}
	if len(words) == 0 {
		return Reply{text: noEntries}
	}
	key := words[len(words)-1]
	regs := snap.selected(s.sources(snap))
	for _, c := range classes {
		if !kept[c] && knownClass(c) {
			return ripeError("Class " + c + " is not kept by this mirror")
		}
	}
	want := func(class string) bool { return len(classes) == 0 || slices.Contains(classes, class) }

	var texts []string
	refused := ""
	switch {
	case inverse != "":
		texts, refused = snap.inverse(ctx, regs, inverse, key, want)
	case mode != 0:
		p, ok := parseSearchPrefix(key)
		if !ok {
			return Reply{text: noEntries}
		}
		m := mode
		if m == 'x' {
			m = 0
		}
		texts, refused = snap.texts(filterHits(snap.search(regs, p, m), want))
	default:
		texts, refused = snap.plain(ctx, regs, key, want, len(classes) > 0)
	}
	if refused != "" {
		return ripeError(refused)
	}
	if len(texts) == 0 {
		return Reply{text: noEntries}
	}
	if keysOnly {
		texts = keyBlocks(texts)
	}
	return Reply{text: strings.Join(texts, "\n") + "\n\n"}
}

func filterHits(hs []hit, want func(string) bool) []hit {
	var out []hit
	for _, h := range hs {
		if want(routeClassOf(h.rt.prefix)) {
			out = append(out, h)
		}
	}
	return out
}

func routeClassOf(p netip.Prefix) string {
	if p.Addr().Is4() {
		return "route"
	}
	return "route6"
}

// inverse answers -i attr value.
func (snap *Snapshot) inverse(ctx context.Context, regs []*Registry, attr, value string, want func(string) bool) ([]string, string) {
	if !slices.Contains(inverseServed, attr) {
		if inverseNotServed[attr] {
			return nil, "Inverse search on " + attr + " is not served by this mirror: it keeps the routing classes only"
		}
		return nil, "Inverse attribute search not supported for " + attr + ", only supported for attributes: " + strings.Join(inverseServed, ", ")
	}
	var texts []string
	switch attr {
	case "origin":
		as, err := types.ParseASN(value)
		if err != nil {
			return nil, ""
		}
		var hs []hit
		for _, r := range regs {
			for _, rt := range r.routes {
				if rt.origin == as && snap.visible(r, rt) && want(routeClassOf(rt.prefix)) {
					hs = append(hs, hit{r, rt})
				}
			}
		}
		return snap.texts(hs)
	case "member-of":
		for _, r := range regs {
			for _, o := range r.claims[strings.ToUpper(value)] {
				if !want(o.Class()) || !snap.objectVisible(r, o) {
					continue
				}
				texts = append(texts, snap.objectServed(r, o))
			}
		}
	case "members", "mp-members":
		for _, r := range regs {
			for _, o := range r.byMember[attr+" "+normMember(value)] {
				if want(o.Class()) {
					texts = append(texts, objectText(o.Raw()))
				}
			}
		}
	case "mbrs-by-ref":
		for _, r := range regs {
			for _, o := range r.byMbrRef[strings.ToUpper(value)] {
				if want(o.Class()) {
					texts = append(texts, objectText(o.Raw()))
				}
			}
		}
	}
	return texts, ""
}

// objectVisible and objectServed are visible and routeText for an object
// kept whole (a claimant): a route goes through them, anything else is
// served as it is.
func (snap *Snapshot) objectVisible(r *Registry, o object.Object) bool {
	if rt, ok := routeOfObject(o); ok {
		return snap.visible(r, rt)
	}
	return true
}

func (snap *Snapshot) objectServed(r *Registry, o object.Object) string {
	if rt, ok := routeOfObject(o); ok {
		rt.text = objectText(o.Raw())
		return snap.routeText(r, rt)
	}
	return objectText(o.Raw())
}

func routeOfObject(o object.Object) (route, bool) {
	switch t := o.(type) {
	case object.Route:
		return route{prefix: t.Prefix, origin: t.Origin}, t.Prefix.IsValid()
	case object.Route6:
		return route{prefix: t.Prefix, origin: t.Origin}, t.Prefix.IsValid()
	}
	return route{}, false
}

// plain answers a lookup by key: a prefix's exact routes, an AS's aut-num,
// a set in every selected registry, or an inet-rtr. A key that is none of
// the first three and names no inet-rtr is refused unless -T limited the
// classes to ones the mirror keeps (restricted).
func (snap *Snapshot) plain(ctx context.Context, regs []*Registry, key string, want func(string) bool, restricted bool) ([]string, string) {
	if p, ok := parseSearchPrefix(key); ok {
		return snap.texts(filterHits(snap.search(regs, p, 0), want))
	}
	if as, err := types.ParseASN(key); err == nil {
		if !want("aut-num") {
			return nil, ""
		}
		for _, r := range regs {
			if an, err := r.src.AutNum(ctx, as, ""); err == nil && an.Raw() != nil {
				return []string{objectText(an.Raw())}, ""
			}
		}
		return nil, ""
	}
	if n, err := types.ParseSetName(key); err == nil {
		var texts []string
		if !want(n.Class().String()) {
			return nil, ""
		}
		for _, r := range regs {
			if set, err := r.src.GetSet(ctx, types.Ref(n)); err == nil && set.Raw() != nil && set.Class() == n.Class().String() {
				texts = append(texts, objectText(set.Raw()))
			}
		}
		return texts, ""
	}
	if want("inet-rtr") {
		for _, r := range regs {
			if rtr, err := r.src.InetRtr(ctx, key, ""); err == nil && rtr.Raw() != nil {
				return []string{objectText(rtr.Raw())}, ""
			}
		}
	}
	if restricted {
		return nil, ""
	}
	return nil, "This mirror keeps only the routing classes; it cannot answer a lookup of " + key
}

// keyBlocks reduces each object to IRRd's -K form, writing each distinct
// block once.
func keyBlocks(texts []string) []string {
	var out []string
	seen := map[string]bool{}
	for _, text := range texts {
		o, _ := rpsl.ParseObject(text)
		if o == nil {
			continue
		}
		class := o.Class()
		key := strings.TrimSpace(o.Key())
		if class == "route" || class == "route6" {
			if p, err := types.ParsePrefix(key); err == nil {
				key = p.String() // IRRd writes the canonical prefix (golden ripe/-K -i origin AS65001)
			}
		}
		lines := []string{class + ": " + key}
		if class == "route" || class == "route6" {
			if a, ok := o.GetFirst("origin"); ok {
				lines = append(lines, "origin: "+strings.TrimSpace(a.Value))
			}
		}
		for _, attr := range []string{"members", "mp-members"} {
			for _, a := range o.GetAll(attr) {
				for _, it := range a.List() {
					if it.Value != "" {
						lines = append(lines, attr+": "+normMember(it.Value))
					}
				}
			}
		}
		block := strings.Join(lines, "\n") + "\n"
		if !seen[block] {
			seen[block] = true
			out = append(out, block)
		}
	}
	return out
}
```

```go
type multiSource struct {
	snap *Snapshot
	regs []*Registry

func (m multiSource) GetSet(ctx context.Context, ref types.SetRef) (object.NamedSet, error) {
	if ref.IsScoped() {
		r := m.snap.byName[ref.Source()]
		if r == nil {
			return nil, resolve.ErrNotFound
		}
		return r.src.GetSet(ctx, types.Ref(ref.Name()))
	}

			return set, nil
		}
	}
	return nil, resolve.ErrNotFound

func (m multiSource) OriginatedRoutes(ctx context.Context, as types.ASN, afi types.AFI) ([]netip.Prefix, error) {

// snapshot has VRPs.
func (snap *Snapshot) expander(regs []*Registry, afi types.AFI) *resolve.Expander {

		src = &rpki.Filter{Src: src, VRPs: snap.opts.VRPs}
	}

// rfcMembers is "!i<name>,1" in RFC mode: a route-set's prefix ranges or an
// as-set's AS numbers, sorted; refused names why it was not expanded.
func (snap *Snapshot) rfcMembers(ctx context.Context, regs []*Registry, name string) (out []string, refused string) {
	n, err := types.ParseSetName(name)
	if err != nil {
		return nil, ""
	}
	e := snap.expander(regs, types.AFIAny)
	switch n.Class() {
	case types.ClassRouteSet:
		rs, err := e.ExpandPrefixRanges(ctx, types.Ref(n))
		if msg := rfcRefusal(err); err != nil {
			return nil, msg
		}
		for _, r := range rs.List() {
			out = append(out, r.String())
		}
	case types.ClassAsSet:
		as, err := e.ExpandAS(ctx, types.Ref(n))
		if msg := rfcRefusal(err); err != nil {
			return nil, msg
		}
		for _, a := range as.List() {
			out = append(out, a.String())
		}
	}
	slices.Sort(out)
	return out, ""
}

		return nil, ""

	if msg := rfcRefusal(err); err != nil {
		return nil, msg
	}
	out := ps.List()
	slices.SortFunc(out, prefixCmp)

// rfcRefusal is the F message for an expansion error, "" for one that
// means "nothing" (a missing set, a set of another class).
func rfcRefusal(err error) string {
	var any *resolve.AnySetError
	var big *resolve.SetTooLargeError
	switch {
	case err == nil, errors.Is(err, resolve.ErrNotFound), errors.Is(err, resolve.ErrSetClass):
		return ""
	case errors.As(err, &any):
		return any.Name.String() + " denotes the whole registry: not expanded in RFC mode"
	case errors.As(err, &big):
		return big.Error()
	}
	return err.Error()
}
```

**Refinement 13.** The defaults: `IdleTimeout` 30 s is IRRd's (`SOCKET_DEFAULT_TIMEOUT`, confirmed by the spike at 30.03 s, and `!t` overrides it per connection, 1-1000 s); `MaxConns` 256, `MaxLine` 1 MiB, `MaxReply` 256 MiB and `QueryTime` 60 s are rpsld's own. IRRd 4.5.3 queues a connection past its `max_connections` (10) and has no line limit (a 1 MB line was answered); rpsld closes a connection past `MaxConns` at once and refuses a longer line — both in `docs/rpsld.md` and the divergences file, without golden cases (they are server behaviour, not answers).

How a connection runs: read a line (its deadline the session's `!t` or `IdleTimeout`), answer it with a context bounded by `QueryTime`, write the reply (its deadline the same), flush when no further command is already buffered (so a pipelined burst goes out in few writes), and stop when a reply closes the connection, the client goes away or a deadline passes. Over `MaxLine` a line is answered `F Line too long: over <MaxLine> bytes` and the connection closed; a reply over `MaxReply` becomes `F Answer larger than <MaxReply> bytes`; a command past `QueryTime` becomes `F Query took longer than <QueryTime>` — both keep the connection, as an IRRd error does.

```go
// Package irrdserver serves resolve/irrdq on sockets: IRRd's query protocol
// and RIPE-style queries on one port, as IRRd 4 does, with explicit limits.
// Each connection is a Session; each command reads the current snapshot
// once, so one answer comes from one snapshot.
package irrdserver

import (
	"bufio"
	"context"
	"errors"
	"fmt"
	"log/slog"
	"net"
	"sync"
	"sync/atomic"
	"time"

	"github.com/rkolesnichenko/rpsl/resolve/irrdq"
)

// Limits bound what one client can take. A zero field is its default.
type Limits struct {
	MaxConns    int           // concurrent connections; one more is closed at once. 256
	IdleTimeout time.Duration // waiting for a command or for the client to read; "!t" overrides it. 30s (IRRd's)
	MaxLine     int           // bytes in one command line, its newline not counted. 1 MiB
	MaxReply    int64         // bytes in one answer. 256 MiB
	QueryTime   time.Duration // one command's evaluation. 60s
}

func (l Limits) withDefaults() Limits {
	if l.MaxConns <= 0 {
		l.MaxConns = 256
	}
	if l.IdleTimeout <= 0 {
		l.IdleTimeout = 30 * time.Second
	}
	if l.MaxLine <= 0 {
		l.MaxLine = 1 << 20
	}
	if l.MaxReply <= 0 {
		l.MaxReply = 256 << 20
	}
	if l.QueryTime <= 0 {
		l.QueryTime = 60 * time.Second
	}
	return l
}

// ErrServerClosed is what Serve returns after Shutdown.
var ErrServerClosed = errors.New("irrdserver: server closed")

// A Server answers IRRd and RIPE-style queries from the snapshot Snapshot
// returns. Set its fields before Serve.
type Server struct {
	Snapshot   func() *irrdq.Snapshot
	Limits     Limits
	Log        *slog.Logger // nil: nothing logged
	LogQueries bool         // one log line per command

	once    sync.Once
	lim     Limits
	sem     chan struct{}
	mu      sync.Mutex
	lns     map[net.Listener]bool
	conns   map[net.Conn]bool
	wg      sync.WaitGroup
	closing atomic.Bool
}

func (s *Server) init() {
	s.once.Do(func() {
		s.lim = s.Limits.withDefaults()
		s.sem = make(chan struct{}, s.lim.MaxConns)
		s.lns, s.conns = map[net.Listener]bool{}, map[net.Conn]bool{}
	})
}

func (s *Server) log(msg string, args ...any) {
	if s.Log != nil {
		s.Log.Info(msg, args...)
	}
}

// Serve accepts connections on ln until Shutdown (then ErrServerClosed) or
// an accept error.
func (s *Server) Serve(ln net.Listener) error {
	s.init()
	if s.closing.Load() {
		return ErrServerClosed
	}
	s.mu.Lock()
	s.lns[ln] = true
	s.mu.Unlock()
	for {
		c, err := ln.Accept()
		if err != nil {
			if s.closing.Load() {
				return ErrServerClosed
			}
			var ne net.Error
			if errors.As(err, &ne) && ne.Timeout() {
				continue
			}
			return err
		}
		select {
		case s.sem <- struct{}{}:
		default:
			s.log("refused: too many connections", "remote", c.RemoteAddr().String(), "max", s.lim.MaxConns)
			c.Close()
			continue
		}
		s.mu.Lock()
		if s.closing.Load() {
			s.mu.Unlock()
			<-s.sem
			c.Close()
			return ErrServerClosed
		}
		s.conns[c] = true
		s.wg.Add(1)
		s.mu.Unlock()
		go s.handle(c)
	}
}

var errLineTooLong = errors.New("line too long")

// readLine reads one line without its "\n", at most max bytes long.
func readLine(br *bufio.Reader, max int) (string, error) {
	var line []byte
	for {
		frag, err := br.ReadSlice('\n')
		line = append(line, frag...)
		if len(line) > max+1 || len(line) == max+1 && line[max] != '\n' {
			return "", errLineTooLong
		}
		if err == nil {
			return string(line[:len(line)-1]), nil
		}
		if !errors.Is(err, bufio.ErrBufferFull) {
			return "", err
		}
	}
}

func (s *Server) handle(c net.Conn) {
	defer func() {
		c.Close()
		s.mu.Lock()
		delete(s.conns, c)
		s.mu.Unlock()
		<-s.sem
		s.wg.Done()
	}()
	sess := irrdq.NewSession(s.Snapshot)
	br := bufio.NewReaderSize(c, 64<<10)
	bw := bufio.NewWriterSize(c, 64<<10)
	idle := func() time.Duration {
		if t := sess.Timeout(); t > 0 {
			return t
		}
		return s.lim.IdleTimeout
	}
	for !s.closing.Load() {
		c.SetReadDeadline(time.Now().Add(idle()))
		line, err := readLine(br, s.lim.MaxLine)
		if errors.Is(err, errLineTooLong) {
			c.SetWriteDeadline(time.Now().Add(idle()))
			bw.WriteString(fmt.Sprintf("F Line too long: over %d bytes\n", s.lim.MaxLine))
			bw.Flush()
			return
		}
		if err != nil {
			return // EOF, a deadline, or Shutdown
		}
		ctx, cancel := context.WithTimeout(context.Background(), s.lim.QueryTime)
		r, err := sess.Do(ctx, line)
		cancel()
		switch {
		case err != nil:
			r = r.Refused("Query took longer than " + s.lim.QueryTime.String())
		case int64(r.Len()) > s.lim.MaxReply:
			r = r.Refused(fmt.Sprintf("Answer larger than %d bytes", s.lim.MaxReply))
		}
		if s.LogQueries {
			s.log("query", "remote", c.RemoteAddr().String(), "line", line, "bytes", r.Len())
		}
		c.SetWriteDeadline(time.Now().Add(idle()))
		if _, err := r.WriteTo(bw); err != nil {
			return
		}
		if r.Close() || br.Buffered() == 0 {
			if err := bw.Flush(); err != nil {
				return
			}
		}
		if r.Close() {
			return
		}
	}
}

// Shutdown stops accepting, lets each connection finish the command it is
// answering, and closes them all; at ctx's end it closes what is left and
// returns ctx's error.
func (s *Server) Shutdown(ctx context.Context) error {
	s.init()
	s.mu.Lock()
	s.closing.Store(true)
	for ln := range s.lns {
		ln.Close()
	}
	for c := range s.conns {
		c.SetReadDeadline(time.Now()) // a connection waiting for a command stops now
	}
	s.mu.Unlock()
	done := make(chan struct{})
	go func() { s.wg.Wait(); close(done) }()
	select {
	case <-done:
		return nil
	case <-ctx.Done():
		s.mu.Lock()
		for c := range s.conns {
			c.Close()
		}
		s.mu.Unlock()
		<-done
		return ctx.Err()
	}
}
```

```go
// FuzzSession: any command lines, through one session over the fixture, in
// IRRd and RFC mode: no panic, and every reply is well formed — an A-frame's
// length is its payload's, any other reply one of C, D, E, an F line, or a

func FuzzSession(f *testing.F) {

		f.Add(c.Send)
	}
	snaps := map[bool]*Snapshot{}
	f.Fuzz(func(t *testing.T, send string) {
		for _, rfc := range []bool{false, true} {
			if snaps[rfc] == nil {
				snaps[rfc] = fixture(t, SnapshotOptions{RFC: rfc})
			}
			snap := snaps[rfc]
			s := NewSession(func() *Snapshot { return snap })
			for _, line := range strings.Split(send, "\n") {

				if err != nil {
					t.Fatalf("Do(%q): %v", line, err)
				}

				r.WriteTo(&b)
				checkReply(t, line, b.String())
				if r.Close() {
					break
				}
			}
		}
	})
}

func checkReply(t *testing.T, line, out string) {
	t.Helper()
	switch {
	case out == "", out == "C\n", out == "D\n", out == "E\n":
	case strings.HasPrefix(out, "F "):
		if strings.Count(out, "\n") != 1 || !strings.HasSuffix(out, "\n") {
			t.Fatalf("%q: a broken F line %q", line, out)
		}
	case strings.HasPrefix(out, "A"):
		nl := strings.IndexByte(out, '\n')
		n, err := strconv.Atoi(out[1:nl])
		if err != nil || len(out) != nl+1+n+2 || !strings.HasSuffix(out, "\nC\n") {
			t.Fatalf("%q: a broken frame %q", line, out)
		}
	default:
		if !strings.HasSuffix(out, "\n\n\n") {
			t.Fatalf("%q: a RIPE-style answer without its ending: %q", line, out)
		}
	}
}
```

**Refinement 14.** `-whois-listen` is gone (Refinement 4); `-rpki-default` (default true) puts the `RPKI` registry in the default selection, last, as RADB lists its pseudo source — `false` gives the goldens' IRRd, whose `sources_default` leaves it out. `-check-dumps` (default 1m) is how often dump files' modification times are looked at; `-nrtm-interval` (default 1m) how often each mirror polls.

What a run does (spec §6):

1. **Parse** the flags; a bad one, or no `-source`, prints usage and exits 2.
2. **Load every input** before listening. A dump registry reads its files through `backend.ReadInput` (gzip or plain) into a `DumpLoader{KeepPolicy: true, KeepRouteText: -keep-route-text}`; its serial is its load count (1 at startup). An NRTMv4 registry builds an `nrtm4.Client{URL, Database: Name, PublicKey, HTTP, MaxAge: 24h, KeepPolicy: true, KeepRouteText}`, with `PublicKey` the key saved in `-state-dir/<NAME>.pem` when there is one, else `-source`'s `key=` file; one `Sync` must succeed; its registry is built from `CopyTo` into a fresh `Corpus` with the same flags, its serial the mirror's version; the key in `Status().CurrentKey` is written back to `-state-dir/<NAME>.pem` (mode 0600) when `-state-dir` is set. VRPs (`-rpki`, a file or an `https://` URL fetched with the run's HTTP client) are read with `rpki.ReadJSON`, `-slurm` applied with `ApplySLURM`, and the `RPKI` registry is built from `WriteRPSL`'s text, serial its load count. Any failure here logs it and exits 3.
3. **Publish** the snapshot — registries in `-source` order, then `RPKI`; default selection the `-source` names (and `RPKI` with `-rpki-default`); `VRPs`, `RFC`, `Version: buildinfo.Version()` — into an `atomic.Pointer`, start an `irrdserver.Server` on `-listen` and log the address.
4. **Refresh**, each input on its own goroutine: a mirror `Sync`s every `-nrtm-interval`, and when its version moved (`Update.To != Update.From` or `Update.Snapshot`) its registry is rebuilt and published; a dump registry is re-read when any of its files' modification times changed (checked every `-check-dumps`) or on `reload` (SIGHUP), its serial then one more; VRPs are re-read every `-rpki-refresh`. Each rebuild happens beside the live snapshot; one mutex serializes publishing (build the next `NewSnapshot` from the current registries with the one replaced, then store it). A failure keeps the registry's previous data and serial and is logged; an NRTMv4 `Stale` update is logged too.
5. **Stop** on ctx's end (SIGTERM, SIGINT): `Shutdown` with `-grace`, exit 0.

Logging is `log/slog` text on stderr: one line per load, sync, swap, refusal and failure, with the registry, serial and duration.

```go
import (
	"errors"

	"github.com/rkolesnichenko/rpsl/types"

// SourceSpec is one -source: a registry and where its data comes from.
type SourceSpec struct {
	Name    string
	Kind    string // "dump" or "nrtm4"
	Paths   []string
	URL     string
	KeyFile string
}

// ParseSourceSpec reads NAME=dump:FILE[,FILE…] or NAME=nrtm4:URL,key=FILE.
// A file name may not hold a comma.
func ParseSourceSpec(s string) (SourceSpec, error) {
	name, rest, ok := strings.Cut(s, "=")
	if !ok {
		return SourceSpec{}, errors.New(`missing "=": want NAME=dump:FILE,… or NAME=nrtm4:URL,key=FILE`)
	}
	n, err := types.ParseSourceName(name)
	if err != nil {
		return SourceSpec{}, err
	}
	if n == rpki.PseudoSource {
		return SourceSpec{}, fmt.Errorf("%s is the registry -rpki makes", n)
	}
	kind, arg, ok := strings.Cut(rest, ":")
	if !ok {
		return SourceSpec{}, fmt.Errorf("%s: missing kind (dump: or nrtm4:)", n)
	}
	spec := SourceSpec{Name: n, Kind: kind}
	switch kind {
	case "dump":
		for _, p := range strings.Split(arg, ",") {
			if p == "" {
				return SourceSpec{}, fmt.Errorf("%s: an empty dump file name", n)
			}
			spec.Paths = append(spec.Paths, p)
		}
	case "nrtm4":
		u, key, ok := strings.Cut(arg, ",key=")
		if !ok || key == "" || strings.Contains(key, ",") {
			return SourceSpec{}, fmt.Errorf("%s: want nrtm4:URL,key=FILE", n)
		}
		pu, err := url.Parse(u)
		if err != nil || (pu.Scheme != "https" && pu.Scheme != "file") || strings.Contains(u, ",") {
			return SourceSpec{}, fmt.Errorf("%s: %q is no https:// or file:// URL", n, u)
		}
		spec.URL, spec.KeyFile = u, key
	default:
		return SourceSpec{}, fmt.Errorf("%s: unknown kind %q (dump or nrtm4)", n, kind)
	}
	return spec, nil
}

// String writes s back as ParseSourceSpec reads it.
func (s SourceSpec) String() string {
	if s.Kind == "nrtm4" {
		return s.Name + "=nrtm4:" + s.URL + ",key=" + s.KeyFile
	}
	return s.Name + "=dump:" + strings.Join(s.Paths, ",")
}
```

```go
func mtimes(spec SourceSpec) ([]time.Time, error) {
	var out []time.Time

		if err != nil {
			return nil, err
		}
		out = append(out, fi.ModTime())
	}

// loadVRPs reads VRPs from a file or an https:// URL, then applies SLURM.
func loadVRPs(ctx context.Context, src, slurm string, hc *http.Client) (*rpki.VRPs, error) {
	var v *rpki.VRPs
	read := func(r io.Reader) (err error) { v, err = rpki.ReadJSON(r); return }
	if strings.HasPrefix(src, "https://") {
		req, err := http.NewRequestWithContext(ctx, http.MethodGet, src, nil)
		if err != nil {
			return nil, err
		}
		resp, err := hc.Do(req)
		if err != nil {
			return nil, err
		}
		defer resp.Body.Close()
		if resp.StatusCode != http.StatusOK {
			return nil, fmt.Errorf("%s: %s", src, resp.Status)
		}
		if err := read(resp.Body); err != nil {
			return nil, fmt.Errorf("%s: %w", src, err)
		}

		return nil, err
	}
	if slurm != "" {

		if err != nil {
			return nil, err
		}
	}
	return v, nil
}
```

```go
// testHTTP, when set, is the HTTP client for everything the run fetches.
var testHTTP *http.Client

type sourceFlags []SourceSpec

func (f *sourceFlags) String() string { return fmt.Sprint(*f) }
func (f *sourceFlags) Set(v string) error {
	s, err := ParseSourceSpec(v)
	if err != nil {
		return err
	}
	for _, o := range *f {
		if o.Name == s.Name {
			return fmt.Errorf("two -source %s", s.Name)
		}
	}
	*f = append(*f, s)
	return nil
}

// state is what the run publishes from: the registries in order and the
// snapshot options, guarded by mu; cur is what the server reads.
type state struct {
	mu   sync.Mutex
	regs []*irrdq.Registry
	opts irrdq.SnapshotOptions
	cur  atomic.Pointer[irrdq.Snapshot]
	log  *slog.Logger
}

// publish replaces the registry of r's name (or, for a nil r, keeps them)
// and the VRPs when v is non-nil, then stores the next snapshot.
func (st *state) publish(r *irrdq.Registry, v *rpki.VRPs) error {
	st.mu.Lock()
	defer st.mu.Unlock()
	regs := slices.Clone(st.regs)
	if r != nil {
		for i := range regs {
			if regs[i].Name() == r.Name() {
				regs[i] = r
			}
		}
	}
	opts := st.opts
	if v != nil {
		opts.VRPs = v
	}
	snap, err := irrdq.NewSnapshot(regs, opts)
	if err != nil {
		return err
	}
	st.regs, st.opts = regs, opts
	st.cur.Store(snap)
	if r != nil {
		st.log.Info("swapped", "registry", r.Name(), "serial", r.Serial())
	}
	return nil
}

// Run is rpsld: it returns the exit status (0 after a clean stop, 2 for a
// bad command line, 3 when an input fails at startup). reload, when not
// nil, re-reads every dump registry (SIGHUP).
func Run(ctx context.Context, args []string, stdout, stderr io.Writer, reload <-chan struct{}) int {
	fs := flag.NewFlagSet("rpsld", flag.ContinueOnError)
	fs.SetOutput(stderr)
	var sources sourceFlags
	fs.Var(&sources, "source", "a registry: NAME=dump:FILE[,FILE…] or NAME=nrtm4:URL,key=PEMFILE (repeatable; the order is precedence)")
	rpkiSrc := fs.String("rpki", "", "VRPs (rpki-client/Routinator JSON): a file or an https:// URL")
	rpkiRefresh := fs.Duration("rpki-refresh", 10*time.Minute, "how often -rpki is re-read")
	slurm := fs.String("slurm", "", "an RFC 8416 SLURM file applied to -rpki")
	rpkiDefault := fs.Bool("rpki-default", true, "select the RPKI registry by default (last), as RADB does")
	listen := fs.String("listen", ":43", "the IRRd and whois query port")
	rfc := fs.Bool("rfc", false, "RFC 2622 answers for !i…,1 and !a (resolve.Expander)")
	keepText := fs.Bool("keep-route-text", false, "keep every route's text: !m route, !r, -i origin")
	stateDir := fs.String("state-dir", "", "a directory for each NRTMv4 mirror's current signing key")
	checkDumps := fs.Duration("check-dumps", time.Minute, "how often dump files' modification times are checked")
	nrtmInterval := fs.Duration("nrtm-interval", time.Minute, "how often each NRTMv4 mirror polls")
	var lim irrdserver.Limits
	fs.IntVar(&lim.MaxConns, "max-conns", 256, "concurrent connections")
	fs.DurationVar(&lim.IdleTimeout, "idle-timeout", 30*time.Second, "waiting for a command (IRRd's default; !t overrides it)")
	fs.IntVar(&lim.MaxLine, "max-line", 1<<20, "bytes in one command line")
	fs.Int64Var(&lim.MaxReply, "max-reply", 256<<20, "bytes in one answer")
	fs.DurationVar(&lim.QueryTime, "query-time", time.Minute, "one command's evaluation")
	grace := fs.Duration("grace", 10*time.Second, "how long open connections get at shutdown")
	logQueries := fs.Bool("log-queries", false, "log every command")
	version := fs.Bool("v", false, "print the version and exit")
	if err := fs.Parse(args); err != nil {
		return 2
	}
	if *version {
		fmt.Fprintf(stdout, "rpsld %s\n", buildinfo.Version())
		return 0
	}
	if len(sources) == 0 || fs.NArg() > 0 || lim.MaxConns < 1 || lim.MaxLine < 1 || lim.MaxReply < 1 ||
		lim.IdleTimeout <= 0 || lim.QueryTime <= 0 || *rpkiRefresh <= 0 || *checkDumps <= 0 || *nrtmInterval <= 0 {
		fmt.Fprintln(stderr, "rpsld: at least one -source, and every limit and interval positive")
		fs.Usage()
		return 2
	}
	log := slog.New(slog.NewTextHandler(stderr, nil))
	hc := testHTTP
	vrpClient := testHTTP
	if vrpClient == nil {
		vrpClient = &http.Client{Timeout: 10 * time.Minute}
	}

	// 2. Load every input.
	st := &state{log: log}
	mirrors := map[string]*nrtm4.Client{}
	for _, s := range sources {
		begin := time.Now()
		var r *irrdq.Registry
		var err error
		if s.Kind == "dump" {
			r, err = loadDump(s, *keepText, 1)
		} else {
			var c *nrtm4.Client
			if c, err = newMirror(s, *keepText, *stateDir, hc); err == nil {
				if _, err = c.Sync(ctx); err == nil {
					r, err = mirrorRegistry(c, s.Name, *keepText)
					mirrors[s.Name] = c
					if kerr := saveKey(*stateDir, s.Name, c); kerr != nil {
						log.Warn("state-dir", "registry", s.Name, "err", kerr)
					}
				}
			}
		}
		if err != nil {
			log.Error("load failed", "registry", s.Name, "err", err)
			return 3
		}
		log.Info("loaded", "registry", s.Name, "serial", r.Serial(), "took", time.Since(begin).Round(time.Millisecond))
		st.regs = append(st.regs, r)
		st.opts.Default = append(st.opts.Default, s.Name)
	}
	var vrps *rpki.VRPs
	if *rpkiSrc != "" {
		v, err := loadVRPs(ctx, *rpkiSrc, *slurm, vrpClient)
		if err == nil {
			var r *irrdq.Registry
			if r, err = rpkiRegistry(v, 1); err == nil {
				st.regs = append(st.regs, r)
				vrps = v
				if *rpkiDefault {
					st.opts.Default = append(st.opts.Default, rpki.PseudoSource)
				}
			}
		}
		if err != nil {
			log.Error("load failed", "registry", rpki.PseudoSource, "err", err)
			return 3
		}
		log.Info("loaded", "registry", rpki.PseudoSource, "vrps", vrps.Len())
	}
	st.opts.VRPs, st.opts.RFC, st.opts.Version = vrps, *rfc, buildinfo.Version()
	if err := st.publish(nil, nil); err != nil {
		log.Error("snapshot", "err", err)
		return 3
	}

	// 3. Serve.
	ln, err := net.Listen("tcp", *listen)
	if err != nil {
		log.Error("listen", "err", err)
		return 3
	}
	srv := &irrdserver.Server{Snapshot: st.cur.Load, Limits: lim, Log: log, LogQueries: *logQueries}
	served := make(chan error, 1)
	go func() { served <- srv.Serve(ln) }()
	log.Info("listening", "addr", ln.Addr().String())

	// 4. Refresh.
	var wg sync.WaitGroup
	for _, s := range sources {
		s := s
		wg.Add(1)
		if s.Kind == "dump" {
			go func() { defer wg.Done(); st.watchDump(ctx, s, *keepText, *checkDumps, reload) }()
		} else {
			go func() { defer wg.Done(); st.follow(ctx, s, mirrors[s.Name], *keepText, *stateDir, *nrtmInterval) }()
		}
	}
	if vrps != nil {
		wg.Add(1)
		go func() { defer wg.Done(); st.refreshVRPs(ctx, *rpkiSrc, *slurm, vrpClient, *rpkiRefresh) }()
	}

	// 5. Stop.
	select {
	case <-ctx.Done():
	case err := <-served:
		log.Error("serve", "err", err)
	}
	sctx, cancel := context.WithTimeout(context.Background(), *grace)
	defer cancel()
	srv.Shutdown(sctx)
	wg.Wait()
	log.Info("stopped")
	return 0
}
```

```go
// watchDump re-reads s when its files change, or on reload.
func (st *state) watchDump(ctx context.Context, s SourceSpec, keepText bool, every time.Duration, reload <-chan struct{}) {
	serial := uint64(1)
	last, _ := mtimes(s)
	tick := time.NewTicker(every)
	defer tick.Stop()
	for {
		forced := false
		select {
		case <-ctx.Done():
			return
		case <-tick.C:
		case _, ok := <-reload:
			if !ok {
				reload = nil
				continue
			}
			forced = true
		}
		now, err := mtimes(s)
		if !forced && (err != nil || slices.EqualFunc(now, last, time.Time.Equal)) {
			continue
		}
		begin := time.Now()
		r, err := loadDump(s, keepText, serial+1)
		if err != nil {
			st.log.Error("reload failed: keeping the previous data", "registry", s.Name, "err", err)
			continue
		}
		serial, last = serial+1, now
		st.log.Info("reloaded", "registry", s.Name, "serial", serial, "took", time.Since(begin).Round(time.Millisecond))
		if err := st.publish(r, nil); err != nil {
			st.log.Error("snapshot", "err", err)
		}
	}
}

// follow syncs the mirror every interval and publishes each new version.
func (st *state) follow(ctx context.Context, s SourceSpec, c *nrtm4.Client, keepText bool, stateDir string, every time.Duration) {
	tick := time.NewTicker(every)
	defer tick.Stop()
	for {
		select {
		case <-ctx.Done():
			return
		case <-tick.C:
		}
		u, err := c.Sync(ctx)
		if err != nil {
			st.log.Error("sync failed: keeping the previous version", "registry", s.Name, "err", err)
		}
		if u.Stale {
			st.log.Warn("stale notification file", "registry", s.Name)
		}
		if err := saveKey(stateDir, s.Name, c); err != nil {
			st.log.Warn("state-dir", "registry", s.Name, "err", err)
		}
		if u.To == u.From && !u.Snapshot {
			continue
		}
		r, err := mirrorRegistry(c, s.Name, keepText)
		if err != nil {
			st.log.Error("rebuild failed", "registry", s.Name, "err", err)
			continue
		}
		st.log.Info("synced", "registry", s.Name, "from", u.From, "to", u.To, "deltas", u.Deltas)
		if err := st.publish(r, nil); err != nil {
			st.log.Error("snapshot", "err", err)
		}
	}
}

// refreshVRPs re-reads the VRPs every interval and publishes them with a
// new RPKI registry.
func (st *state) refreshVRPs(ctx context.Context, src, slurm string, hc *http.Client, every time.Duration) {
	serial := uint64(1)
	tick := time.NewTicker(every)
	defer tick.Stop()
	for {
		select {
		case <-ctx.Done():
			return
		case <-tick.C:
		}
		v, err := loadVRPs(ctx, src, slurm, hc)
		if err != nil {
			st.log.Error("VRP refresh failed: keeping the previous VRPs", "err", err)
			continue
		}
		r, err := rpkiRegistry(v, serial+1)
		if err != nil {
			st.log.Error("VRP refresh failed: keeping the previous VRPs", "err", err)
			continue
		}
		serial++
		if err := st.publish(r, v); err != nil {
			st.log.Error("snapshot", "err", err)
		}
	}
}
```

```go
// Command rpsld is an IRRd-compatible mirror: it keeps registries in memory
// — from dumps, NRTMv4 mirrors and RPKI VRPs — and answers IRRd's query
// protocol and RIPE-style whois on one port, as IRRd 4.5.3 answers, so
// bgpq4, IRRToolSet and rpslq run against it unchanged.
//
//	go install github.com/rkolesnichenko/rpsl/resolve/cmd/rpsld@latest
//	rpsld -source RIPE=nrtm4:https://nrtm.db.ripe.net/nrtmv4/RIPE/update-notification-file.jose,key=ripe.pem \
//	      -source RADB=dump:radb.db.gz -rpki https://…/vrps.json -keep-route-text
//
// Run rpsld -help for its options; docs/rpsld.md has the rest.
package main

import (
	"context"
	"os"
	"os/signal"
	"syscall"

	"github.com/rkolesnichenko/rpsl/resolve/internal/rpsld"
)

func main() {
	ctx, stop := signal.NotifyContext(context.Background(), os.Interrupt, syscall.SIGTERM)
	hup := make(chan os.Signal, 1)
	signal.Notify(hup, syscall.SIGHUP)
	reload := make(chan struct{})
	go func() {
		for range hup {
			select {
			case reload <- struct{}{}:
			case <-ctx.Done():
				return
			}
		}
	}()
	code := rpsld.Run(ctx, os.Args[1:], os.Stdout, os.Stderr, reload)
	stop()
	os.Exit(code)
}
```

```go
package rpsld

import (
	"context"
	"os"
	"path/filepath"
	"runtime"
	"strings"
	"testing"
	"time"

	"github.com/rkolesnichenko/rpsl/resolve/irrdq"

// TestRealDataServe (opt-in: RPSL_REALDATA=<the directory
// scripts/fetch-irr-dumps.sh fills>) loads RIPE's routing-class dumps and
// RADB's dump as two registries, with and without -keep-route-text, and
// logs what it costs: load time, heap, one registry's reload time and the
// heap while the old and the new registry are both alive. It then asks the
// served snapshot a sample of queries and requires answers.
func TestRealDataServe(t *testing.T) {
	dir := os.Getenv("RPSL_REALDATA")
	if dir == "" {
		t.Skip("set RPSL_REALDATA to the directory scripts/fetch-irr-dumps.sh fills")
	}
	var ripe []string
	for _, class := range []string{"as-set", "route-set", "rtr-set", "filter-set", "peering-set", "aut-num", "inet-rtr", "route", "route6"} {
		ripe = append(ripe, filepath.Join(dir, "ripe", "ripe.db."+class+".gz"))
	}
	specs := []SourceSpec{
		{Name: "RIPE", Kind: "dump", Paths: ripe},
		{Name: "RADB", Kind: "dump", Paths: []string{filepath.Join(dir, "radb", "radb.db.gz")}},
	}
	heap := func() uint64 {
		runtime.GC()
		var m runtime.MemStats
		runtime.ReadMemStats(&m)
		return m.HeapAlloc
	}
	for _, keepText := range []bool{false, true} {
		base := heap()
		begin := time.Now()
		var regs []*irrdq.Registry
		for _, s := range specs {
			r, err := loadDump(s, keepText, 1)
			if err != nil {
				t.Fatal(err)
			}
			regs = append(regs, r)
		}
		loaded := time.Since(begin)
		held := heap() - base
		begin = time.Now()
		again, err := loadDump(specs[0], keepText, 2)
		if err != nil {
			t.Fatal(err)
		}
		reload := time.Since(begin)
		peak := heap() - base
		t.Logf("keep-route-text=%v: loaded RIPE and RADB in %v, heap %d MB; RIPE reloaded in %v; heap with both RIPE registries alive %d MB",
			keepText, loaded.Round(time.Second), held>>20, reload.Round(time.Second), peak>>20)
		snap, err := irrdq.NewSnapshot([]*irrdq.Registry{again, regs[1]}, irrdq.SnapshotOptions{})
		if err != nil {
			t.Fatal(err)
		}
		s := irrdq.NewSession(func() *irrdq.Snapshot { return snap })
		s.Do(context.Background(), "!!")
		for _, cmd := range []string{"!iAS-DECIX", "!aAS-DECIX", "!gAS3333", "!maut-num,AS3333", "!r193.0.0.0/21,o"} {
			r, _ := s.Do(context.Background(), cmd)
			var b strings.Builder
			r.WriteTo(&b)
			if !strings.HasPrefix(b.String(), "A") {
				t.Errorf("keep-route-text=%v: %s answered %q", keepText, cmd, b.String())
			}
			t.Logf("%s: %d bytes", cmd, b.Len())
		}
		runtime.KeepAlive(regs)
	}
}
```

```go
// A registry built from RPSL text answers IRRd's commands as IRRd does.
func Example() {
	c := &resolve.Corpus{KeepPolicy: true}
	for _, text := range []string{
		"as-set: AS-X\nmembers: AS1, AS-Y\nsource: RIPE\n",
		"as-set: AS-Y\nmembers: AS2\nsource: RIPE\n",
		"route: 192.0.2.0/24\norigin: AS2\nsource: RIPE\n",
	} {
		o, _ := rpsl.ParseObject(text)
		obj, _ := rpsl.Decode(o)
		c.Put(obj)
	}
	reg, _ := irrdq.NewRegistry("RIPE", 1, c)
	snap, _ := irrdq.NewSnapshot([]*irrdq.Registry{reg}, irrdq.SnapshotOptions{})
	s := irrdq.NewSession(func() *irrdq.Snapshot { return snap })
	for _, cmd := range []string{"!!", "!iAS-X,1", "!aAS-X", "!j-*"} {
		r, _ := s.Do(context.Background(), cmd)
		r.WriteTo(os.Stdout)
	}
	// Output:
	// A8
	// AS1 AS2
	// C
	// A13
	// 192.0.2.0/24
	// C
	// A11
	// RIPE:N:0-1
	// C
}
```
